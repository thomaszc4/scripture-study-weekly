# Scripture Study Weekly

The weekly Come, Follow Me content for the Scripture Study Links Chrome extension, a personal
study tool. The extension reads `weekly.json` about twice a day, so new weeks appear without
reinstalling anything.

- `weekly.json`: each week's dates, reading, a short overview, study concepts with verse
  references, and questions to ponder. The overviews, concepts and questions are written for
  this project; the Church's own lesson is linked for each week.
- The extension accepts only plain text, scripture references and links to
  churchofjesuschrist.org from this file. Nothing about the reader is sent anywhere.

This is a personal study project. It is not made, approved or endorsed by The Church of Jesus
Christ of Latter-day Saints.
